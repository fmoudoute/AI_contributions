## Running the examples

The examples use the Luckin Coffee Q1 2026 earnings call transcript (`scripts/files/`). Run the scripts from the `scripts/` folder:

```bash
cd scripts
pip install numpy matplotlib onnxruntime tokenizers huggingface_hub
python embedding_from_scratch.py   # Part 3
python embedding_pretrained.py     # Part 3
python retrieval_eval.py           # Part 4
python ann_from_scratch.py         # Part 4
```

Parts 5 and 6 use a local LLM through [Ollama](https://ollama.com), so there is no API cost:

```bash
ollama pull qwen2.5:7b
ollama pull llama3.1
ollama pull hf.co/LiquidAI/LFM2.5-1.2B-Instruct-GGUF:Q4_K_M
python generation_demo.py          # Part 5
python eval_end_to_end.py          # Part 6
```

The Part 2 tokenizer experiments are in `scripts/playground_tokenizer.ipynb`.
